# 实际实现与验证状态

版本：0.1.7，2026-10-23。

本文件区分设计目标与当前实现。产品不是 Automic Vault 的移植，也没有继承 macOS 的 Hardened Runtime 或应用身份隔离保证。

## 已实现

- Windows 本地可执行程序与真实管理界面：添加、编辑、删除、启用目标，锁定与本机解锁，使用记录、组件诊断。
- 统一保险库 SVG 标识、黑白灰配色与浅色/深色适配；界面贴合原生 Windows 窗口，不再额外绘制外层圆角边框和阴影，内部卡片保留圆角。重新组织连接详情、集成和设置页面，改写产品文案。技术信息与保护范围在设置中按需展开，不改变实际安全边界。
- 三类连接详情移除重复的“连接授权 / 管理授权”卡片；连接授权开关统一保留在“编辑连接”中，详情侧栏仅呈现对应的 SSH 接入、数据库测试或网页登录操作。
- 管理界面由本机回环 HTTP 提供，通过一次性启动入口建立 HttpOnly/SameSite 会话，验证 Host、Origin 与自定义请求头；不向 CLI 返回管理会话 URL 或令牌。
- 本地命名管道公共工具协议，显式用户 ACL 并拒绝网络身份；公开操作没有密码、私钥或 Cookie 导出。
- DPAPI 包装数据密钥、AES-256-GCM 加密保险库，原子文件替换与用户 ACL。当前使用加密 JSON 文档，不是设计候选中的 SQLite。
- SSH Agent：Ed25519 公钥枚举、认证数据签名、拒绝任意数据签名及远程密钥管理；可明确启用标准 Windows OpenSSH Agent 管道。
- SSH 支持普通公钥认证及 `publickey-hostbound-v00@openssh.com`；修复新版 OpenSSH 与真实服务器协商主机绑定格式时被误拒绝的问题。签名覆盖完整原始认证数据，仍拒绝未知方法、无效主机公钥和额外尾部数据。此支持不等于实现了目标绑定或 `session-bind` 扩展。
- 当前 SSH 使用授权为“已解锁 + 目标启用”，没有逐次批准弹窗；状态与管理界面提供最近一次签名的安全诊断，不保存会话标识或签名内容。skill 明确原生客户端路径、非交互参数以及拒绝不是待批准状态。
- SSH 客户端接入提供本机启用/禁用开关，启动默认禁用。禁用同时阻止标准/专用管道上的新签名，等待正在签名的操作完成，关闭本地 Agent 连接并释放标准管道；不能追溯撤销已经建立的远端会话。
- 附带 Claude 请求文件记录入口和本地秘密扫描器；只返回计数，支持常见文本编码检查和不完整证据判定，不提供原始秘密读取工具。详见 `context-verification.md`。
- PostgreSQL/MySQL 连接、连接测试、schema、SQL 与参数、有限结果输出、直接密码回显处理、TLS 默认校验。
- agent-browser 0.39.1 原生程序及实际凭据插件协议；浏览器内部短时单次授权、目标 origin 校验、可见独立会话、登录成功标记检测、快照/点击/关闭。
- 网站支持“账号和密码”“仅密码表单”“浏览器密码弹窗”三种配置。账号密码保留原 provider 路径；仅密码方式由本机适配器通过私有 Chrome 调试连接注入，不要求伪造账号。支持自动 prompt 和指定按钮触发的 prompt，不包含 HTTP Basic / 系统认证弹窗。
- 默认要求 HTTPS；远程 HTTP 需用户在本机连接配置中显式允许，界面说明网络传输未加密。密码表单明确区分填写、提交与检测到成功标记。
- CLI、薄 stdio MCP、三种 Agent 的使用说明生成/安装。未自动修改宿主权限。
- Skill 的说明、适用描述与操作指引统一为中文，保留固定命令与生成标识，旧集成仍可识别并备份更新。MCP 工具说明使用中文；集成页提供基于真实程序路径和数据目录的 Codex / JSON 配置及复制功能。
- 补充 `mcp-integration.md`，明确 11 个 MCP 工具、stdio 桥接和命名管道转发机制，以及 SSH 仍需宿主调用原生客户端的限制。

## 已完成的验证

- Windows DPAPI/ACL 下加密持久化、锁定、禁用、损坏文件拒绝。
- 由真实 Go SSH 客户端完成本机 SSH 认证与命令，私钥留在 Vault；拒绝任意字符串签名与密钥删除。
- 新增主机绑定签名回归：旧版本对符合 OpenSSH 格式的请求复现拒绝，修复后通过；完整签名可验证，缺失/非法主机公钥、普通认证多余尾部和用户名不匹配仍拒绝。
- PostgreSQL/MySQL 真实驱动与本机协议 fixture 的认证、查询、失败处理和密码回显过滤。
- 公开接口不存在原始凭据导出，provider 直接调用拒绝取密，浏览器授权拒绝跨 origin、过期及重复消费。

- Windows 自带 OpenSSH 客户端通过标准 Agent 命名管道完成真实本机 SSH 登录与命令；自定义 IdentityAgent 在本机版本中未生效，因此产品明确采用可选择启用的标准管道。
- agent-browser + 无头 Chrome 实际提交本机测试表单、登录成功标记验证、同一会话继续获取页面；登录返回及快照未包含随机测试密码或 Cookie。
- 0.1.6 使用随机含引号、反斜线和中文的密码实测仅密码表单、页面加载 prompt、按钮触发 prompt，并验证跨 origin 弹窗拒绝。故意回显密码的页面文本快照已脱敏，公共结果不含测试 Cookie 或私有 CDP 地址。这些是本机 fixture 验证，不代表已登录用户提供的网站。
- 真实管理界面在 Chrome 中完成保险库创建、三类目标录入、公开状态不含凭据、锁定/解锁、Agent 接入页与手机宽度检查。
- 0.1.6 界面实测仅密码模式隐藏并取消账号必填，切换模式保留输入，HTTP 默认拒绝及本机显式选择，登录方式和入口选择器保存、编辑及公开状态不含测试密码。
- 0.1.3 界面通过真实浏览器的搜索/类型筛选、SSH 开关、取消/确认删除、弹窗关闭、深色模式及 320/360/600/900/1200 宽度检查；浅色、深色、表单、详情及确认弹窗截图均完成视觉检查。
- MCP 初始化、通知与公共工具清单格式，管理界面认证、Host/Origin 检查及一次性启动入口重放拒绝。
- 用户反馈已在 Claude Code 跑通 SSH、数据库及网站三个实际登录场景；此反馈是功能验收，尚不是其真实请求内容已扫描的证据。
- 本机 Claude Code 2.1.302 连接模拟模型接口，可产生未截断的 `.request.json`；未使用真实 API 密钥或外部模型调用。

## 与设计文档的明确取舍

1. 首版以单用户后台进程和独立浏览器应用窗口交付；没有 Electron/.NET 运行时要求，也尚未提供原生托盘。
2. 数据存储采用加密单文档，目标数与本地记录规模有限；数据格式带版本，可后续迁移。
3. 账号密码表单通过短时单次内部 grant 使用凭据；仅密码模式通过受管理浏览器的私有本机认证连接注入。两者均不伪称实现了强进程身份或同用户恶意代码隔离。
4. 原型中的“模拟登录”和预置连接均未进入实际产品。
5. 使用授权是本机用户对目标启用的许可，不是远端命令白名单或业务审批。
