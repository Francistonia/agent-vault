# 验证密码是否进入 Claude Code 的模型请求

适用：Windows Agent Vault 0.1.6、Claude Code CLI。当前机器实际版本为 2.1.302；已用该版本连接本机模拟模型接口，验证能够生成请求文件。该验证不使用真实模型服务或生产凭据，也不代表已经扫描了你的业务测试会话。

## 要验证什么

登录成功是功能验证。密码没有出现在聊天窗口，只能说明界面没展示。要检查“模型请求上下文”，优先检查 Agent **实际准备发送的请求体**中的 system、messages、工具调用参数和工具结果。

| 检查对象 | 能得到的证据 | 限制 |
| --- | --- | --- |
| 聊天窗口 | 可见对话中没有展示密码 | 隐藏工具内容、其他请求可能未展示 |
| 会话 JSONL、生成脚本和工具日志 | 可取得的本地记录没有命中测试秘密 | 不能替代全部模型请求 |
| 本地记录的模型请求参数 | 该次捕获的请求中是否包含测试秘密 | 需确认捕获完整、测试用例覆盖；不是所有工具的永久保证 |
| 自己控制的模型网关实际接收内容 | 请求经过网关后的进一步证据 | 需要另行配置；本版不会自动改变模型出口 |

Claude Code 官方支持 `OTEL_LOG_RAW_API_BODIES=file:<dir>`：以文件形式保存未截断的请求/响应 JSON，事件只携带文件引用。内联模式 `=1` 默认可能截断，不适合用来证明完整请求没有秘密。此功能默认关闭。[官方监控文档](https://code.claude.com/docs/en/monitoring-usage#api-request-body-event)

## 准备独立测试

1. 分别创建 SSH、数据库、网站的测试目标。数据库与网站使用不同的随机测试密码，建议至少 24 个字符；SSH 使用新生成的测试私钥和测试账号。
2. 测试秘密由你在密码管理器或本机终端生成，在 Vault 的本机窗口录入。不要让 Agent 生成、读取或输入这些秘密，也不要把它们写进提示词、文件名或命令参数。
3. 使用一个空的测试工作目录、新的 Claude 对话。测试网站/数据库不要把认证密码作为正常业务内容返回。
4. 以下记录功能会在本机生成请求正文，因此本轮只使用测试账号。扫描在本机运行，报告不打印秘密或命中行；不要让 Agent 读取原始请求文件来代替扫描。

## 一、记录模型请求

在你自己打开的 PowerShell 中进入测试工作目录，运行完整包中的：

```powershell
& 'C:\workspace\safe\dist\tools\Start-ClaudeContextAudit.ps1'
```

解压在其他位置时替换产品路径。该脚本：

- 创建独立的 `%LOCALAPPDATA%\AgentVault-Audit\时间-随机编号` 目录，并限制文件权限到当前 Windows 用户及 SYSTEM。
- 仅为这次 Claude 进程启用请求文件记录，日志输出选择本机 console，指标和追踪关闭，不配置外部遥测收集器。
- 启动 Claude；退出后恢复当前脚本进程的相关环境变量。
- 显示请求文件个数；如果是 0，明确标记没有取得请求证据。

这是测试入口，不是产品日常启动入口，也不会自动开启生产会话的全文记录。

## 二、让 Agent 走三个认证路径

只告诉 Agent 目标名称和业务动作，例如：

```text
/agent-vault 登录测试 SSH 服务器，执行 df -h。
/agent-vault 连接测试数据库，执行 SELECT 1。
/agent-vault 登录测试网站，查看登录后的首页。
```

每个动作完成后再让它总结结果，使认证后的工具结果也出现在下一次模型调用中。确认它使用 Vault 的连接、托管浏览器会话和原生 SSH，没有自写取密脚本。

至少覆盖：

| 场景 | 成功路径 | 失败路径 |
| --- | --- | --- |
| SSH | 已启用接入、已解锁、正确公钥认证并执行只读命令 | 锁定、停用目标、禁用 SSH 接入、用户名不匹配 |
| 数据库 | 认证、查询、返回业务结果 | 在本机窗口暂时设为错误测试密码、连接失败、TLS 失败 |
| 网站 | 认证、登录后页面快照、点击页面后继续同一会话 | 错误测试密码、表单校验失败、登录页快照 |

网站分别覆盖账号密码表单、仅密码表单、页面自动出现的 JavaScript prompt、按钮触发 prompt。所有方式仍使用同一个 `browser login --target` 公共入口；密码只在本机窗口录入，不交给公共填写或弹窗参数。另用本机 fixture 验证跨 origin 弹窗被拒绝。远程 HTTP 网站需用户在本机明确允许，传输未加密的风险与上下文检查分别判断。

故意回显密码是另一项输出脱敏测试，只能由你控制的专用 fixture 完成。不要将“正常登录不泄露”和“任意网站恶意回显都能挡住”混为一个承诺。当前公开浏览器工具没有截图接口，本轮文本扫描不能代替其他工具截图的人工检查。

结束时退出 Claude，记下脚本显示的捕获目录。

## 三、在本机扫描，不把秘密交给模型

以数据库测试密码为例，在你自己的终端运行：

```powershell
& 'C:\workspace\safe\dist\tools\Test-ContextSecrets.ps1' `
  -Paths 'C:\Users\你的账号\AppData\Local\AgentVault-Audit\本次目录' `
  -RequireRequestCapture
```

脚本随后会以隐藏输入方式询问测试密码。输入值只在这个本机进程内匹配，不会变成命令参数、报告内容或 Agent 的工具返回。网站密码另运行一次，不要省略。

检查 SSH 私钥：

```powershell
& 'C:\workspace\safe\dist\tools\Test-ContextSecrets.ps1' `
  -Paths 'C:\Users\你的账号\AppData\Local\AgentVault-Audit\本次目录' `
  -PrivateKeyPath 'C:\你的测试材料\fixture_ed25519' `
  -SkipPasswordPrompt -RequireRequestCapture
```

这里只传私钥**路径**，扫描器在本机读取文件并匹配，不打印内容。加密私钥的解锁口令另外按普通秘密扫描一次。SSH 公钥和指纹可以出现在上下文，不属于私钥泄露。

扫描内容包括原值、常见 JSON 转义、URL 编码、UTF-8 Base64 和解析 JSON 后的字符串，并检查私钥 PEM 标记。它不是任意编码、任意分块、图片或加密数据的识别器。内存使用结束后释放引用，不承诺托管字符串在内存中得到可证明的清除。

返回只含计数：

| conclusion | 意义 |
| --- | --- |
| `MATCH_FOUND` | 找到测试秘密或私钥标记。停止这条路径的保护声明，在本机排查；报告不回显命中内容。退出码 1 |
| `INCOMPLETE` | 无文件、无请求文件、读取/解析失败、文件超限或存在不支持文件，不能据此判定通过。退出码 2 |
| `NO_MATCH_IN_SCANNED_TEXT` | 本次所选文本中没有匹配项；还要核对 `request_files > 0`、用例覆盖与全部秘密是否分别扫描。退出码 0 |

先运行随包的 `Test-ContextScanner.ps1` 可做正反例自检：它在本机生成随机秘密，验证普通、JSON/Unicode 转义、Base64、私钥标记、无效文件及缺少文件的识别，输出测试结果，不输出测试秘密。测试材料自动清理。

## 四、补充会话记录

Claude Code 的默认本地会话位置为 `~/.claude/projects/<project>/<session-id>.jsonl`；位置和写入行为可能被用户配置改变，内部格式也会随版本变动。只选这轮测试的会话及其工具结果文件，使用同一扫描器的 `-Paths` 再扫描，**不加** `-RequireRequestCapture`。[官方会话文档](https://code.claude.com/docs/en/sessions#where-transcripts-are-stored)

测试工作区中的生成脚本、工具 stdout/stderr 保存文件也应扫描。不要仅检查最终回答；不要求你把日志或密码发回聊天。如果需要产品协助诊断，先提供扫描的计数报告和失败代码。

## 如何写验收结论

可写：“Windows、Claude Code 具体版本、Agent Vault 具体版本、三个测试目标，在列出的成功/失败用例中，捕获 N 个请求，分别扫描各测试密码、SSH 私钥及口令，未命中；读取失败 0，跳过文件 0。”

不能据此写“永久保证所有 Agent、所有工具、所有页面和所有返回路径都没有密码”。本版还没有把这轮手动验收做成管理界面中的一键认证报告，也没有自动扫描你已完成的生产测试。
