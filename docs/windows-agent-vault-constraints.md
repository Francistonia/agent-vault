# Windows Agent Vault 约束与验收清单

版本：0.1.6  
日期：2026-10-23  
状态：设计要求及验收清单；各项实际完成情况见 implementation-status.md。

主文档：[产品与技术设计](windows-agent-vault-design.md)。

## 1. 要求级别

- **必须**：发布前满足；不满足不能将相关流程标为支持。
- **应当**：默认实施，偏离需记录原因和用户影响。
- **后续**：首版不作承诺，不得在产品界面伪报完成。

产品帮助支持的认证流程避免将密码、私钥、Token 放进模型上下文。不保证任意工具收到凭据后的行为、全部输出路径或同用户恶意进程均受约束。

| SEC-11 | 内部凭据通道与 Agent 可见通道分离，内部原始消息不进入通用日志 | 日志与 IPC 审查 |
| SEC-12 | 产品已支持的直接凭据回显路径有处理；处理失败不返回原始输出 | 回显与故障注入测试 |
| SEC-13 | 限制请求尺寸、超时和协议版本；未知版本不返回秘密 | 畸形消息测试 |
| SEC-14 | 关闭、禁用和撤销的效果明确，不宣称可撤回第三方已经收到的凭据 | 生命周期测试与文案审查 |
| SEC-15 | 本产品不承诺拦截用户主动发给模型的密码 | 用户说明 |

## 4. SSH 场景约束

| ID | 要求 | 验证证据 |
| --- | --- | --- |
| SSH-01 | 用标准 Agent 签名完成认证，不向客户端导出私钥 | 完整公钥登录测试 |
| SSH-02 | Agent 列密钥仅返回公钥及非秘密元数据 | 协议响应检查 |
| SSH-03 | 验证当前 Windows SSH 版本及实际 Agent 端点 | 兼容矩阵与诊断输出 |
| SSH-04 | 与现有 Agent 冲突需明确提示并支持还原，不静默替换 | 共存与卸载测试 |
| SSH-05 | 不自动关闭服务器主机密钥校验 | 新主机/变化主机测试 |
| SSH-06 | 默认不启用 Agent Forwarding；不默认开放保险库密钥变更协议 | 配置及协议测试 |
| SSH-07 | 无法验证目标或命令时不展示虚假的细粒度授权信息 | 签名请求审查 |
| SSH-08 | SSH 账号密码认证不是首版必需，未实现不能标为支持 | 产品范围检查 |
| SSH-09 | 提供本机禁用入口，禁用同时阻止标准及专用管道的新签名，并明确已有远端会话不因此退出 | 禁用/重新启用、已连接 Agent、管道释放测试 |

| DB-10 | 大整数、decimal、时间、NULL、二进制的输出格式明确 | 类型兼容测试 |

## 8. 验收用例

测试用专门生成的随机标记密码、私钥和会话材料。它们只在本地测试准备环节录入；不把标记本身放入 Agent 提示词，再据此判断泄露。

| 用例 | 操作 | 预期 |
| --- | --- | --- |
| A01 | 新用户安装并添加 SSH、数据库、网站三个测试目标 | 不编辑配置文件即可开始支持的登录流程 |
| A02 | Agent 请求 SSH 登录并执行查询命令 | 认证成功；模型记录无私钥和解锁口令 |
| A03 | Vault 锁定后 SSH 请求签名 | 提示本机解锁或拒绝；不导出密钥绕过 |
| A04 | 通过 PostgreSQL 和 MySQL 查询 | 返回结构化结果；调用参数不含密码 |
| A05 | 密码错误、数据库不可达或 TLS 失败 | 错误清楚且不含连接串密码 |
| A06 | 测试服务直接回显本次托管密码 | 在已声明支持的文本输出路径中被处理 |
| A07 | 已支持的流式输出将秘密拆在相邻块 | 仍按覆盖声明处理，或该路径明确不支持 |
| A08 | 网站标准/分步表单登录，随后查看其他页面 | 同一浏览器会话继续；模型无需知道密码 |
| A09 | 表单失败并触发文本快照、截图、异常日志 | 已支持路径不暴露填充值；状态不误报成功 |
| A10 | 将凭据引用用于其他网站或直接启动 provider | 拒绝不匹配用途；不打印密码 |
| A11 | 网站出现验证码或 MFA | 用户本机接管后继续，或清楚报告需人工 |
| A12 | 无凭据、取消录入、窗口超时 | 无聊天取密回退；任务有明确状态 |
| A13 | 更新凭据后重新认证 | 使用新值；已有会话是否继续需如实说明 |
| A14 | 卸载产品 | 用户原工具与配置可恢复；保险库保留/删除选择有效 |
| A15 | 启用 SSH 后禁用，再重新启用 | 禁用期间两个管道均不能产生新签名，标准管道释放；重新启用后可继续认证；已建立远端会话的边界明确 |
| A16 | 添加无账号的仅密码表单、自动 prompt 和按钮触发 prompt | 本机录入后可登录，工具参数与结果无密码；切换方式保留尚未保存的输入 |
| A17 | 登录页重定向到不同 origin 的密码弹窗 | 拒绝使用密码，返回安全错误；不向新站提交凭据 |
| A18 | 添加远程 HTTP 网站 | 默认拒绝保存；本机明确允许后可使用，界面保留未加密说明 |

验收检查范围包括：实际可取得的模型请求/会话记录、公共 CLI 参数、MCP 参数与结果、stdout/stderr、产品日志、诊断包、生成配置和脚本、浏览器快照与截图。

如果某宿主不开放原始模型请求，不能写成“已检查全部模型请求”；应说明检查了哪些本地会话和工具记录，以及缺少的证据。

## 9. 发布阻断项

以下情况必须修复或取消对应支持声明：

1. 公共工具、provider 直接调用或诊断正常路径能返回真实密码/私钥。
2. 认证异常自动回退为让用户把密码发到聊天。
3. 未验证的工具版本被界面标为已受保护。
4. 管道允许未经约束的远程取密。
5. 产品自身的日志、命令参数或临时文件写入真实凭据。
6. 自动关闭 TLS/SSH 身份验证来让登录“成功”。
7. 浏览器仅完成填写就无条件报告登录成功。
8. 安装或卸载无提示破坏已有 SSH Agent、浏览器配置或其他 Agent 工具。

对明确披露的第三方未知路径、管理员攻击和全部业务操作治理，不因首版未实现就无限扩大范围；它们属于既定边界或后续事项。
